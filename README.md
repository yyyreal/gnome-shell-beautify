# Gnome美化

为 GNOME Shell 的 Dock（顶部系统栏）与应用程序栏（概览中的应用图标栏）提供独立或联动的背景美化效果。

## 功能

- 原始、透明、模糊、磨砂玻璃、纯色、渐变六种效果
- Dock 与应用程序栏联动或独立配置；联动时共用 Dock 配置，解除后恢复各自独立配置
- 模糊半径、透明度、亮度、色调、渐变和外观细节参数
- 所有效果统一采用 `0% = 完全不透明、100% = 完全透明`
- Dock 快捷图标，可弹出快速效果菜单并进入设置
- 滑块等参数停止调整后延迟应用，减少连续重绘；效果选项和联动开关立即应用
- 设置页面同步显示实际联动参数，并分别报告两端的配置应用状态
- 中文、英文及跟随系统语言
- 性能保护、电池模式、预设导入导出和恢复默认

## 支持版本

GNOME Shell 46–51。扩展仅面向 GNOME 46 及以上版本。

## 安装

```bash
gnome-extensions install gnome-beautify@yyyreal.github.com-v1.0.8.zip --force
```

注销并重新登录后启用：

```bash
gnome-extensions enable gnome-beautify@yyyreal.github.com
```

## 1.0.8 联动修复与验证

- 联动时，Dock 和全部应用程序栏在同一次提交中读取同一份不可变配置；设置页的效果、滑块数值、颜色及预览也跟随 Dock。
- 联动不再覆盖原有应用程序栏独立配置，解除联动后可恢复。快捷菜单联动时也不会改写这份独立配置。
- 系统主题、概览动画、电池状态及栏位重建只刷新已提交配置，不提前应用正在调整的参数，也不重置其延迟计时。
- 监测系统对应用程序栏背景样式的覆盖并恢复已提交效果，禁用扩展时还原最新的系统样式。
- 单个目标失败不阻断其他目标；背景未就绪或应用失败会在 300、800、1600 毫秒后有限重试。持续失败会保留失败状态，不无限循环。
- 状态栏等待扩展确认，分别显示已应用、隐藏待显示、未就绪、缺失或失败，不再用设置页倒计时模拟成功。
- 打包前运行 `node --experimental-vm-modules --test tests/blur-surface.test.mjs`、JavaScript 语法检查及 GSettings schema 严格编译。

27 项自动测试覆盖 36 种联动组合、36 条效果切换路径，以及设置页有效参数、连续调整、主题覆盖、隐藏恢复、
多屏单端失败、有限重试和禁用清理。测试使用模拟 Actor / GTK 对象执行实际模块，
不等同于 GNOME 50 实机或 GPU 渲染验证。

### 实机联动检查

1. 开启联动，在 Dock 页面依次选择六种效果；应用程序栏页面应显示相同效果和参数。
2. 模糊或磨砂使用有细节的壁纸，透明度设为 60%，半径从 0 调到 60；滑块数值立即改变，两端实际参数应在停止调整后一起应用。
3. 在等待应用期间打开/关闭概览或切换系统深浅色，不应抢先应用拖动中的参数。
4. 隐藏的原生 Dash 会显示“已配置，等待目标显示”；打开概览后应应用最新已提交配置。
5. 解除联动，应恢复之前的应用程序栏独立参数；禁用扩展后应恢复系统原有背景。

透明度 100% 会移除模糊层，0% 的不透明底色会遮住模糊；判断模糊半径是否生效时应使用中间透明度。

## 1.0.7 布局修复

- 模糊背景层不再插入顶部栏的纵向布局，避免额外增加一行。
- 采样层移到 Dash 的离屏渲染区域外；Ubuntu 自带 Dock 的采样层保留在滑动、裁剪容器内。
- 仅绘制层跟随背景的位置、尺寸、缩放和显隐，包装容器固定为零尺寸，不复制目标的布局请求。

自动测试覆盖 Actor 层级、零占位、坐标换算、半径/联动/延迟应用、显隐和销毁清理，
不等同于 GNOME 的 GPU 渲染测试。实机检查时，使用有细节的壁纸，透明度设为 60%，
分别将模糊与磨砂半径从 0 调到 60，停止调整后等待设置的应用延迟；检查顶部没有多出
横条，应用程序栏图标仍清晰，并检查隐藏、重新显示及禁用扩展后的恢复情况。
